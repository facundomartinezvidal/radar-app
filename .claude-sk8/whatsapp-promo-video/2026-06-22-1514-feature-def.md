# Feature: WhatsApp Bot Promo Video (Remotion)
Date: 2026-06-22
Status: Approved
OpenSpec Change: openspec/changes/whatsapp-promo-video/

## Business Context
**Problem Statement**: RADAR's headline differentiator — register/query expenses over WhatsApp — has no promo video. The pending `WhatsAppBot` clip in `promo-feature-videos` is only a thin hook→mock→payoff blueprint.
**Target Users**: Prospective users / social-distribution audience (18–35 AR).
**Success Metrics**: A renderable 1080×1920 ~25s MP4 that clearly communicates link-then-chat value, usable in 2026 deliverables and social.
**Priority**: P2 — marketing asset, no production-system risk.

## Decisions (confirmed with user)
- New OpenSpec change `whatsapp-promo-video` (richer than the generic blueprint).
- ~25s · 1080×1920 (9:16) · 30fps → 750 frames.
- Chat = query-then-load.
- Silent (MusicSlot wired, no track).

## Narrative (4 phases on a 750-frame timeline)
1. 0–90 (3s): intro kinetic words (hook).
2. ~90–360 (~9s): in-app "Vincular WhatsApp" connect flow — generar código → code reveals → "Abrir WhatsApp".
3. ~360–630 (~9s): WhatsApp-style chat — "¿Cuánto gasté este mes?" → bot summary → "Coto $38.500" → "✓ Gasto registrado · Comida · $38.500".
4. ~630–750 (4s): outro words → centered RADAR logo + tagline.

## Architecture / Reuse
- Workspace: isolated `promo/` Remotion package (1080×1920, 30fps).
- Reuse: `Device`, `KineticText`, `LogoSweep`/`Tagline`, `MusicSlot`, theme `tokens`/`anim`/`fonts`.
- New: `promo/src/screens/WhatsAppLink.tsx`, `promo/src/screens/WhatsAppChat.tsx`, `promo/src/compositions/WhatsAppBot.tsx`.
- Modify: `promo/src/Root.tsx` (register), `promo/scripts/render-all.mjs` (add `WhatsAppBot` + missing `Tickets`).
- Copy source (read-only): `app/(protected)/profile/whatsapp.tsx`.

## Edge cases / notes
- WhatsApp green vs RADAR dark: intentional, scoped to chat phase; crossfade transition + final logo re-anchor brand.
- Chat readability: stagger bubble entrances + typing indicators; tune in Studio.
- No jest suite in `promo/`; verification is visual scrub + sample render. App's 1871-test baseline untouched.

## Acceptance Criteria
