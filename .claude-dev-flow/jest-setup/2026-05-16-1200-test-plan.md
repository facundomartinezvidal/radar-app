## Test Strategy

### Auth Store (`stores/auth-store.ts`)
- Unit test with no React/RN rendering; calls `useAuthStore.getState()` directly.
- Reset state in `beforeEach` to guarantee test isolation.
- Cover: initial state values, `setSession` with a valid session, `setSession(null)`, `reset()`.

### useSession hook (`hooks/use-session.ts`)
- Uses `renderHook` from RNTL to test the hook in a React context.
- Drives store changes via `useAuthStore.setState` inside `act()`.
- Cover: initial values, reactive updates when store changes, `isAuthenticated` derivation.

### storage (`lib/storage.ts`)
- Mocks `supabase.storage.from` per-test using the global mock from `jest.setup.ts`.
- Mocks `globalThis.fetch` to simulate local file reads.
- Cover: bucket-missing 404 (message match + statusCode numeric + warns), success path (path prefix, extension, bucket name, publicUrl), non-bucket errors re-throw.

## Mocking Strategy

| Dependency | Mock location | Reason |
|------------|---------------|--------|
| `@/lib/supabase` | `jest.setup.ts` global | All tests need it; prevents real network calls |
| `expo-secure-store` | `jest.setup.ts` global | Not available in Jest/Node environment |
| `expo-constants` | `jest.setup.ts` global | Provides test env values for Supabase config |
| `globalThis.fetch` | Per-test in `storage.test.ts` | Only storage tests need this |
| `supabase.storage.from` | Per-test in `storage.test.ts` | Need different return values per test |
